# QUESTÕES DO PRIMEIRO DIA 


## 1 O que é Git? 
````markdown 
- Uma linguagem de programação
- Um sistema de controle de versão local
- Um banco de dados
- Um sistema de controle de versão remoto
````

## 2 Qual comando inicializa um novo repositório Git em uma pasta?
````markdown  
- git start
- git new
- git init
- git create
````
## 3 O que é um repositório git? 
````markdown 
- Um diretório que contém apenas arquivos de código
- Um local que armazena arquivos e o histórico completo de versões
- Um servidor remoto.
- Um tipo de branch principal
````

## 4 Para que serve o GitHub?
````markdown 
- Executar código
- Hospedar repositórios e colaborar em projetos
- Substituir o Git
- Criar banco de dados
````

## 5 Qual a diferença entre Git e GitHub?
````markdown 
- Git é online e GitHub é offline
- Git é um sistema de versionamento, GitHub é uma plataforma de hospedagem
- Não existe diferença
- GitHub substitui o Git
````

## 6 Qual afirmação descreve corretamente a relação entre Git e GitHub?
````markdown 
- Ambos são ferramentas locais de versionamento
- Git depende obrigatoriamente do GitHub para funcionar
- Git é o sistema de versionamento e o GitHub é uma plataforma que o utiliza para hospedagem e colaboração
- GitHub substitui completamente o Git
````

## 7 O que é um commit?
````markdown 
- Um erro no código
- Um envio de alterações com histórico
- Um tipo de branch
- Um arquivo
````
## 8 O que diferencia visualmente, embora de forma oculta, uma pasta comum de um repositório Git local?
````markdown 
- O ícone da pasta que muda para o logotipo do GitHub.

- A necessidade de uma senha sempre que a pasta é aberta.

- A presença da pasta oculta .git.

-A impossibilidade de deletar arquivos manualmente.

````
## 9 Qual é a ordem correta dos três estados de um arquivo no fluxo de trabalho do Git?
````markdown 
- Initial, Secondary e Final.

- Untracked, Staged e Committed.

- Draft, Review e Published.

- Committed, Staged e Untracked.

````
## 10 Antes de realizar o primeiro commit, por que é necessário configurar o 'user.name' e o 'user.email'?
````markdown

- Para identificar o autor de cada mudança no histórico do projeto.

- Para que o GitHub possa enviar notificações de marketing para o usuário.

- Para aumentar a velocidade de upload dos arquivos.

- Para converter o código em uma linguagem que o Git entenda.
````
## 11 Qual comando é utilizado para visualizar as mudanças feitas em um arquivo antes que elas sejam movidas para o estado de commit?
````markdown

- git status
- git log
- git check
- git diff

````
## 12 Para que serve o comando git remote -v?
````markdown
- Ver versões de arquivos
- Listar os repositórios remotos configurados
- Validar commits
- Ver conflitos

````
## 13 Durante o fluxo de versionamento no Git, qual comando move alterações do estado “modified” para “staged”?
````markdown 
- git commit

- git add

- git merge

- git push
````
